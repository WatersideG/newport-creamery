# Newport Creamery — Spin to Win

Mobile-first spin-to-win web prototype for Newport Creamery's QR code campaign. Customers scan a QR on the truck, enter their info, spin the wheel, and win a treat redeemable in store.

## Live demo

https://watersideg.github.io/newport-creamery/

## Files

- `index.html` — the prototype (single self-contained file, no build step)
- - `newport-logo-reverse.svg` — white-text logo variant for dark backgrounds
  - - `screenshots/` — reference renders of all four screen states
   
    - ## Demo controls
   
    - Tap the gold ribbon at the top of the page to force any of the eight prize outcomes for client review. Remove the ribbon block before launch.
